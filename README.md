# IMBALANCE: Wrath of Olympus — 3D Spartan Action & FVG Trading Game

A **God of War II** inspired 3D action-runner built with **Three.js**, **TypeScript**, and **Vite**. Sprint across 3D candlestick bridges as a **Spartan Warrior**, jump over Hades spike traps, collect floating Dollar Orbs, smash Order Block Chests, and Blade-Slash inside glowing Fair Value Gaps!

## Controls
* **Jump (Double Jump supported):** Tap **JUMP** button, **Swipe Up**, or press **W / Up Arrow**
* **Blades of Chaos Slash / FVG Execution:** Tap **BLADE SLASH**, **Tap Screen**, or press **Spacebar**
